OSC support

终端程序发来的能力请求，
边界要说清楚。

这里整理 ianvs 当前支持的 OSC 序号、协议来源、核心能力和主要场景。解析成功不等于自动获得剪贴板、文件、URL 或系统权限。

Reading the matrix

“官方”不是一张统一的序号表。

OSC 定义了控制字符串的基本形式，具体序号大多由终端生态扩展。这里把 xterm 和广泛采用的约定称为事实标准，其余按协议维护者标注。

事实标准 xterm 和被多个终端采用的通用约定。
三方与社区规范 Kitty、iTerm2、VS Code、ConEmu、urxvt 和 UAPI。
权限边界 剪贴板、文件、URL 和变量披露继续经过产品权限与当前会话校验。

xterm & common

xterm 与通用约定

覆盖标题、颜色、目录、链接、通知、字体、文本剪贴板和能力查询。

OSC：xterm 与通用约定
OSC 来源 状态 核心能力 主要场景
OSC 0/1/2/l/L xterm；l/L 来自 Sun/CDE 支持 设置窗口标题和图标名，保留分号与拆分 UTF-8。 Tab 标题、窗口标题、会话识别。
OSC 4/104 xterm + iTerm2 查询别名 支持 0–255 调色板设置、查询和重置；-1/-2 默认色查询。 TUI 动态换色、主题探测。
OSC 5/6/105/106 xterm + iTerm2 双命名空间支持 xterm 属性色；iTerm2 增量 Tab RGB 与默认色恢复。 搜索高亮、任务 Tab 着色。
OSC 7 iTerm2/VTE 等通用扩展 支持 上报当前目录、主机和用户，拒绝畸形路径。 CWD 展示、远程会话标识。
OSC 8 iTerm2/VTE 通用扩展 支持 超链接 URI、id 身份、命中测试和打开目标。 编译日志、文档与文件链接。
OSC 9 iTerm2/ConEmu 安全子集 有界纯文本通知。 后台命令完成提醒。
OSC 9;4 ConEmu/Windows Terminal 支持 正常、不确定、错误、清除进度，百分比限制 0–100。 构建、下载、长任务进度。
OSC 9;9 ConEmu/Windows Terminal 适配器支持 上报绝对 CWD，不覆盖既有远程身份。 Windows shell 目录同步。
OSC 10–19 / 110–119 xterm 支持 前景、背景、光标、选择和高亮动态颜色及恢复。 应用级主题、选择色和光标色。
OSC 23 安全兼容处理 不支持 有界空操作，不修改标题栈。 消费旧输入并避免副作用。
OSC 50 xterm 支持 会话级 TrueType 字体族设置和查询。 临时切换等宽字体、能力探测。
OSC 52 xterm 文本子集 权限控制的 Base64 文本写入和读取请求。 远程程序复制文本、剪贴板同步。
OSC 60/61/62 xterm 只读支持 查询允许、拒绝和可用 OSC 子能力，不改变权限。 子进程启动时能力协商。

Kitty

Kitty 协议

覆盖颜色、指针、多单元格文本、macOS 拖放目标、交互通知和多 MIME 剪贴板。

OSC：Kitty
OSC 来源 状态 核心能力 主要场景
OSC 21 Kitty 有界子集 批量颜色设置、查询和重置。 Kitty 应用换色、颜色能力探测。
OSC 22 Kitty 支持 30 种指针、设置/重置、栈和状态查询。 链接、拖放和文本选择反馈。
OSC 66 Kitty 支持 定宽/自然宽、倍数/小数缩放、对齐和多单元格文本。 大标题、数学与富文本式展示。
OSC 72 Kitty macOS 接收端子集 拖放查询、目标注册和用户放入的 MIME 数据。 从 Finder 向当前终端拖入文件或文本。
OSC 99 Kitty 安全交互子集 通知生命周期、查询、纯文字按钮和固定回报。 可交互任务通知；不执行通知命令。
OSC 5522 Kitty 安全子集 多 MIME 二进制剪贴板、授权读取、令牌和分块回复。 图片、富文本和文件引用粘贴。

iTerm2

iTerm2 协议

OSC 1337 下的能力很多，因此按会话、外观、终端内交互和主机权限边界拆开说明。

OSC：iTerm2
OSC 来源 状态 核心能力 主要场景
OSC 133 FinalTerm/iTerm2 支持 Prompt、命令、输出生命周期、语义 Prompt 和嵌套 shell 恢复。 Prompt 跳转、上次输出、命令块搜索。
OSC 1337 会话元数据 iTerm2 支持子集 CurrentDir、RemoteHost、UserVar、Badge、Mark、版本和单元格尺寸。 Shell 集成、目录与远程身份。
OSC 1337 变量与 Unicode iTerm2 权限/外观子集 ReportVariable 精确授权；Unicode 8/9 宽度切换和栈。 安全披露终端变量、兼容旧字符宽度。
OSC 1337 颜色与光标 iTerm2 支持子集 SetColors、CursorShape、光标行高亮和样式恢复。 动态主题、光标外观和当前行定位。
OSC 1337 终端内交互 iTerm2 支持子集 剪贴板写入、标注、块折叠/渲染、按钮、清屏和清 Captured Output。 命令块、结果折叠、终端内文档与操作。
OSC 1337 图像/文件/外部动作 iTerm2 权限控制子集 内联图像、显式保存下载、确认打开 URL、受限 attention。 图片预览、文件下载、链接确认和提醒。
OSC 1337 RequestUpload 等 iTerm2 明确不授权 不读取本地文件；StealFocus、SetProfile 不授权。 阻止子进程扩大主机权限。
OSC 21337 iTerm2 外观子集 增量 Tab 指示点、状态文本和状态颜色。 Tab 上展示构建、部署和连接状态。

Other protocols

其他兼容协议与 Ianvs 私有协议

这些能力来自编辑器、其他终端、社区规范或 Ianvs 自身，不能通过终端品牌猜测支持。

OSC：其他兼容协议与 Ianvs 私有协议
OSC 来源 状态 核心能力 主要场景
OSC 633 VS Code 适配器子集 A–E/P 生命周期、命令关联和 CWD 属性。 兼容 VS Code shell integration。
OSC 777 urxvt 安全子集 结构化标题和消息通知。 兼容已有通知脚本。
OSC 934 Ianvs 私有 ianvs-osc934/1 支持 最多 64 个带 ID/标签的并行进度状态，支持查询和移除。 同一 Pane 内展示多个任务。
OSC 3008 UAPI 社区规范 元数据支持 v1.0 层级上下文、更新、返回、子级关闭和恢复。 Shell、容器与远程上下文建模。

Boundaries

支持协议，不等于放开主机权限。

当前产品边界

  • 现代 OSC 主要面向 Xterm256；VT220 配置通常会拒绝或静默消费。
  • OSC 23 是安全空操作，不会修改标题或 CSI 标题栈。
  • OSC 72 当前只实现 macOS 接收端，不读取远程文件或目录。
  • OSC 52 只处理文本；多 MIME 数据通过 OSC 5522。
  • OSC 99 不自动聚焦，不播放声音，不接收图标，也不执行通知命令。
  • OSC 1337 RequestUpload、StealFocus 和 SetProfile 不获得主机权限。
