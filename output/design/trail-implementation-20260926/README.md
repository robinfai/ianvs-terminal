# Trail 标题栏与侧边栏实现验收

这是实际 Flutter 组件渲染，终端使用测试数据。macOS 原生红黄绿窗口按钮不在 Flutter 截图内。

## 已实现

- 侧边栏模式将布局切换、居中的 Trail 名称和设置齿轮集中到左侧标题栏，右侧留空。两个按钮使用相同中心线和点击尺寸。
- 顶部 tabs / 侧边栏 tabs 使用成对矢量图标；按钮表示点击后要切换到的布局。
- 设置齿轮打开命令面板，桌面搜索、回放和设置操作由命令面板进入。
- 当前会话所属目录的文件夹和路径使用主题强调色，其余目录使用默认文字颜色；选中会话也使用强调色。
- 侧栏默认 280 逻辑像素，通常限制在 240–480，最大不超过窗口宽度的 45%。窗口缩小时临时收窄，恢复窗口或切换布局后保留用户宽度。
- 分栏有 8 像素拖动区域，默认不画线；悬停显示边界，拖动时强调。键盘聚焦也显示边界，并支持左右方向键、Home 和 End。
- macOS 原生窗口拖动排除区跟随侧栏宽度，避免拖动窗口与点击按钮、调整侧栏冲突。

## 验证

相关 Flutter 回归测试通过：侧栏宽度边界、恢复与布局切换、终端实例保留、目录高亮、命令操作、回放焦点恢复、辅助技术操作和手机端入口。截图测试覆盖亮暗主题及最窄窗口、大字号，无布局溢出。

静态分析无问题；macOS Debug 构建成功；7 项原生标题栏点击与窗口拖动区域测试通过。验证主机为 macOS 27.0（26A428），其他受支持 macOS 版本未在本次实际运行验证。最低部署版本保持原有配置。
