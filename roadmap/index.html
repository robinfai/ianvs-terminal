Roadmap

从 macOS 开始，走向更多桌面。

当前重点是把 macOS 本地终端体验打磨稳定，再逐步补齐更多桌面平台和工作流能力。每个阶段都会区分已可用、正在推进和长期方向。

现在可用

macOS 本地终端主链路

macOS 本地 shell、tab 和窗口壳、复制粘贴、滚动、resize、基础 profile/defaults，以及可运行的验证入口。

接下来

补齐配置功能的人工验收

继续检查配置里还没有完成人工验收的功能，把可用性、边界状态和交互细节逐项跑通，再根据真实使用感受做体验优化。

未来

走向更多桌面平台

更多桌面平台、更完整的 workspace 能力、更清楚的平台状态和验证证据。未来方向不会写成当前能力。
