# PR #12：草稿收起键盘与 CI 修复

日期：2026-10-12。修复基于 `0951d441622ad888125eed45da0597a3d0e64ddc`，仍面向 `composer`，保持 Draft，不合并。

## 草稿高度与输入状态

手机录屏对应的旧构建中，空输入为 56 逻辑像素，两行草稿收起键盘后仍为 116。定向回归在 402 宽复现 116，在 320 宽因内容折行复现 138。

原因是阅读态判定把非空草稿、附件也当作持续编辑。现在仅输入焦点、未结束的 composing 或展开编辑器维持编辑态；阅读态显示一行预览，保留同一 TextEditingController、完整文字、选区和展开入口。输入重新获得焦点后恢复多行编辑及来源控件。

系统收起键盘且 composing 已结束时也进入阅读态；页面进入时已有软键盘的场景会初始化当前键盘状态。收起键盘把焦点留在 AI 阅读页，使硬件 Escape 继续进入只读观察，而不是把输入权交给底层终端。

新增回归覆盖深浅色、320/402 宽与短横屏、中文多行/路径/emoji、选区、重新编辑、系统键盘消失及零请求/零终端写入。既有 TUI 测试继续验证实际终端尺寸、网格和输入所有权。

## 原 CI 三项失败

原运行：[38148482678](https://github.com/robinfai/ianvs-terminal/actions/runs/38148482678)，5 项成功、3 项失败。

| 失败任务 | 失败原因与修复 |
| --- | --- |
| Flutter terminal (macos-26) | 9 张 Composer 基线缺失，11 张 Shell/设置基线落后。逐张审核同一次 CI 的原始候选图，只更新这 20 张；未改比较器、容差或 macOS 27 基线。 |
| macOS app integration and release | 触控板回归从负滚动偏移开始，触发边缘回弹摩擦，64 点移动实得约 52.25 点。等待阅读锚点恢复后从有效区间内开始手势，保留每步 ±0.5 点、惯性和输入权限断言，并断言未越界。后续 CI 的控制器偏移仍有 0.8 点惰性布局补偿，改为与现有滚动归属组件回归一致，测量同一可见输出实际移动的 64 点；精度不变，额外保持父滚动位置单向变化断言。 |
| iOS simulator and device | 模拟器已启动，但 Flutter 的 generic iOS Simulator destination 无法匹配。构建明确传入后续测试使用的模拟器 UDID。首轮修复的远端重跑仍只暴露真机目的地，因此补齐 Debug/Profile/Release 的 `SUPPORTED_PLATFORMS`（iphoneos、iphonesimulator），并输出 Debug 目的地发现日志；保留真机默认 Release 启动和 Archive 配置。新增两项原生 iOS 草稿高度回归，保留原生单元测试、沙箱、ABI 导出和设备 Release 构建。 |

远端复验 `38232550156` 另暴露真实 PTY 测试的两处竞态：准备结果到 FIFO 输出之间可能插入一次合法的空轮询，旧断言却假定总计数必定只加 1；测试直接释放外置 ProviderContainer，页面尚未卸载的微任务仍可能读取它。现按这段事件窗口的实际请求数严格核对计数，并继续要求只有一个 native-hint 请求，保留唤醒时限与完整刷新生命周期断言；清理先卸载页面、排空微任务，再释放容器。未调整运行时轮询策略。

同轮仓库总门禁还暴露 Rust `prompt_sp_clear_sequence_marks_cleared_marker_row_dirty` 的 200ms 睡眠竞态：忙碌主机可能在首次读取前合并标记与清屏两段输出。改为关闭输入回显、读取到标记帧后才发送 PTY 握手推进清屏，保留第 0 行必须清除的断言，以 SessionGuard 保证失败时也关闭子进程；独立 pub 包镜像由同步工具生成。

视觉门禁之后的旧阻塞也一并修复：11 项手机测试改用现有任务菜单、详情页和主操作；重连后用捕获的迟到回调验证不会重复连接，避免测试在新帧前向已替换的旧布局注入点击。Shell 会话事件处理移入现有事件模块，入口回到 1700 行以内，未提高任何架构门槛。两份现行实现记录迁出冻结归档目录；旧 TOKEN_MAP 的六条机器本地证据链接标为历史路径，保留来源哈希，不伪装成仓库内可下载产物。
