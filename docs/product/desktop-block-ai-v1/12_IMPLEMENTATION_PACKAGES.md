## 并行与依赖

W01先完成；W02与W03可以分view/test并行，但统一owner/target模型后整合。W05–W08依D1状态合同，可并行独立组件但不能各自改同一FocusNode/controller。W09–W12在行为稳定后统一tokens。W13开始前冻结候选；发现产品问题回对应工作包修复并重拍影响面。

UI实现、测试设计与证据采集可由不同执行者承担；最终在同一实际App集成验证。禁止因并行子任务互相覆盖用户未提交工作；canonical修改合流后统一sync到standalone。

每个包输出：变更文件、保留能力、新行为、测试命令/真实输出、必拍shot id、已知缺口与下一依赖。不给时间估算，不以工作包完成数冒充验收通过数。
