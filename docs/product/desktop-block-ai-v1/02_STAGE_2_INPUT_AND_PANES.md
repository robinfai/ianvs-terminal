# D2 PRD · 键鼠、Composer 与多窗格交互

**目标：**键盘与指针在多pane、多状态下可预测，长草稿和长输出不丢上下文。

**依赖：**D1的显示/控制/审批边界明确；遵守14键盘与几何合同。

**非目标：**不把手机六行预览、软键盘Return规则或固定字号拷贝到桌面；不擅增provider。

## 1. 用户故事与交付判断

作为常用键盘和多窗格的用户，我需要每个按键、滚轮手势和焦点切换都作用在我正在操作的对象上；补全、阅读、编辑和审批之间切换，不会把内容送错终端。

本阶段每项需求均有独立case，表中步骤还须拆出其中包含的负向子场景。已有能力满足则补回归，不重复开发。所有“应/必须”为验收要求，不是本轮已完成声明。

## 2. 逐条需求

### D2-R01 · 键盘分发与主操作决策（P0）

**必须行为：**建立焦点作用域优先级：IME → 当前 modal/menu → Composer 候选/历史 → 当前编辑器 → Block 导航 → pane/window 动作。Enter/Tab 与按钮调用同一 primary-action 决策；快捷键按宿主已注册映射显示。

**边界与实现：**Command 编辑有选中候选时 Enter/Tab 只采用，无候选且 lease 就绪才执行；AI Enter 发送、Shift+Enter 换行，IME 优先。Raw/TUI 中不拦截 Shell 所需 Tab/Ctrl+R/Ctrl+C。审批无全局无条件 Enter 批准，只有明确聚焦的有效批准按钮才可键盘激活。

**验收：**`D2-T01`。一次按键只命中当前作用域；不会同时采用并执行或向后台 pane 写入。

### D2-R02 · 多行编辑、粘贴与撤销（P0）

**必须行为：**沿用原生多行编辑、选择、撤销/重做和独立灰字模型。桌面 Dock 根据行数增长到明确上限后内部滚动，保留空间查看结果；长草稿可展开编辑，完成只保存。

**边界与实现：**粘贴文本在 Composer 中只入本地草稿，不受多行内容自动执行；复制排除未接受灰字。64 KiB 作为本地编辑压力样本，不意味着绕过提交协议大小上限；超限显式拒绝并保留原稿。Raw 粘贴继续既有策略，不混入 Composer。

**验收：**`D2-T02`。编辑不写 PTY；undo/redo和选区准确；超过提交能力时不截断、不发送残片。

### D2-R03 · 真实中文输入法优先（P0）

**必须行为：**macOS 实际拼音输入法的 composing 确认与应用提交分开。输入候选、切换输入法、中文路径、emoji、组合字符与选区编辑均需验证；不以 controller 人工 composing 值替代实测。

**边界与实现：**不得由外层 CallbackShortcuts 吃掉字符确认键；焦点回调必须复查 active window/pane/editor generation。候选关闭只结束 composing，不等于执行或发送。

**验收：**`D2-T03`。确认候选零 PTY/AI起始调用；最后显式提交仅一次；不乱码、不串 pane。

### D2-R04 · 补全、详情与本地 I/O 授权（P1）

**必须行为：**保留 Tab 按需、唯一候选补齐、多候选选择、选中项详情、目录/文件/alias/scripts 类型。宽 pane 候选+侧详情；窄 pane 为可展开内联详情，不越过 pane 边界盖住邻 pane 的操作。

**边界与实现：**自动候选默认与偏好沿用现状；关闭时 Tab 仅授权本次查询。不能为了新 UI 擅增远程文件/历史 provider、执行脚本或跨机器读取本地目录。整段选中不盲覆盖，光标中间替换保留右参数。

**验收：**`D2-T04`。权限边界未变；候选采用不执行；说明可完整阅读且不丢焦点。

### D2-R05 · 历史与独立灰字（P1）

**必须行为：**↑在第一视觉行或已有 Ctrl+R 打开真实当前会话历史；最近命令靠近输入；搜索、取消、采用清楚。灰字独立显示，不进入复制、提交和选区；接受后才成为草稿。

**边界与实现：**↑在多行内部先移动光标；Esc 恢复进入历史前的草稿/选区；滚动历史时 hover 不重定位。远端历史不可用时准确降级，不拿本地历史充当远端。

**验收：**`D2-T05`。取消原样恢复；采用不执行；当前会话来源明确。

### D2-R06 · Block 选择、键盘导航和复制（P0）

**必须行为：**标题点击选块，Cmd/平台既有修饰键多选、Shift范围选；输出拖选是文本选择，不无故变成整块多选。复制命令/输出/两者以及书签等既有能力保持；批量操作显示块数与作用域。

**边界与实现：**复制优先级明确：focused editable selection → output text selection → selected blocks；不可把另一 pane 的陈旧 selected set 放入剪贴板。大输出复制受预算且失败可恢复，不悄悄只复制当前画面。

**验收：**`D2-T06`。文本与块复制不混淆；选择不会执行/上传；跨 pane 不串内容。

### D2-R07 · 桌面 Block 高度和手动展开（P1）

**必须行为：**未手动展开时整个 Block 高度上限为其所在 pane 的终端内容可用高度 H 的1/3；扣除标题/状态/工具区域后，输出高度按终端行高向下取整。短输出自然高度，不固定手机六行。

**边界与实现：**H 不含窗口顶栏、底部状态栏、Composer 和外部工具条。若短窗/文字放大导致标题状态本身超过H/3，改为清晰摘要+阅读器并记录退化，不能裁掉安全元信息；用户手动展开可超过默认上限且按会话保留。

**验收：**`D2-T07`。默认上限按pane而非窗口；整数行无裁切；例外不压缩字号/触发执行。

### D2-R08 · 滚轮、触摸板与双层滚动（P1）

**必须行为：**桌面保留块内输出和外层时间线滚动。指针位于输出时先滚块内；已到边界时新的滚动手势可交外层；一次手势归属锁定，禁止同一delta重复消费造成跳跃。支持横向长行阅读且不吞纵向手势。

**边界与实现：**用户回看时停止tail follow；新输出、hover选中项或补全更新不能强拉位置。触摸板惯性需物理手测；无法检测手势阶段的鼠标轮以确定性边界规则处理并记录，不伪称所有硬件等价。

**验收：**`D2-T08`。不会同时滚两层/跳到尾；有“回到最新”；不把滚轮转发给已完成块PTY。

### D2-R09 · 查找、过滤与原生阅读器（P1）

**必须行为：**保持全文/单块查找、大小写/正则、过滤/反选/上下文、原生分页与完整保留输出复制。查找结果显式显示作用域、匹配计数/上限；打开Reader恢复到匹配原始行。

**边界与实现：**过滤只改变显示，不修改 grid 与默认全部输出复制语义；若新增复制筛选结果必须单独命名，不替换原按钮。无效正则、分页版本失配和淘汰都有清楚状态；关闭查找不清原草稿。

**验收：**`D2-T09`。正确区分显示过滤与数据；不拼错页；降级说明可见且回到原阅读锚点。

### D2-R10 · 多 pane 焦点与执行隔离（P0）

**必须行为：**同一窗口可同时存在命令编辑、AI任务、只读输出与TUI pane；每pane独立输入意图、草稿、模式、任务。只有key window内活动pane的有效owner接收人手输入；后台AI仅按其原guard执行获批操作。

**边界与实现：**活动边框仅围终端区域，不包Composer造成双框；不要为了“聚焦”重置终端。pending approval所在pane与active pane不同，应提示定位原pane，不能自动迁移。不同session并行AI不等于同PTY多owner。

**验收：**`D2-T10`。零错目标写入；所有草稿/模式独立；A通知不抢B焦点。

### D2-R11 · Tabs、拖放与关闭保护（P0）

**必须行为：**保留tab排序、溢出、既有pane移动/分屏布局；拖动只改变拓扑，session identity保持。多tab待审批用轻量计数/标记，不塞入第二条导航；关闭动作使用实际tab/pane粒度。

**边界与实现：**拖拽文件到Composer仅按已有明确策略插入/附加，不自动运行或上传；拖移tab过程中不产生键位输入。实现不存在的跨窗口tab迁移不在本轮偷偷新增，记录能力边界。

**验收：**`D2-T11`。无误关、无新PTY替代；取消不丢草稿；菜单作用于正确对象。

### D2-R12 · 窗口前后台与异步焦点（P0）

**必须行为：**切至其他应用、窗口失活、最小化、modal打开后，晚到输出/回复不能抢回焦点。重新激活只恢复用户上次有效阅读/编辑意图；消息通知只提示，不自动唤醒写入。

**边界与实现：**遵循Flutter FocusNode生命周期：不能每次build重建或跨多个视图共享一个可写FocusNode。没有多窗口产品能力时以两个应用窗口验证焦点边界，不新增window manager。

**验收：**`D2-T12`。无后台抢焦点；键位不落到终端；返回不自动批准/执行。

### D2-R13 · 窗口尺寸、缩放与多显示器（P1）

**必须行为：**按实际约束适配960×600、1280×720、1440×810、1920×1080；320逻辑宽pane是压力样本，不是手机模式。桌面测试文字缩放1/1.5/2及实际系统DPI；主动作/目标保留。

**边界与实现：**逻辑尺寸、像素尺寸、DPR、系统缩放和应用文字缩放分列；移动到不同DPI显示器后终端cell测量与overlay锚点重算，不累计倍乘。仅数据重绘不伪造resize事件。

**验收：**`D2-T13`。无overflow、模糊位置漂移/裁字；fallback恢复同语义行；未发生错误提交。

### D2-R14 · 鼠标情境菜单与可发现性（P1）

**必须行为：**菜单在点击对象附近且限制在当前窗口/屏幕可见区；hover与右键不改变执行目标或草稿。安全关键操作、只读状态和禁用原因始终有可见或可聚焦说明，不只靠tooltip。

**边界与实现：**点击选中行、菜单采用和详情拖选需维护焦点；Esc先关闭最内层菜单。鼠标点击仅激活非key窗口时，不顺带执行危险动作；关键提交需当前有效焦点/目标检查。

**验收：**`D2-T14`。菜单不越界；首次激活不误批准；关闭恢复触发点且不触发下层。

### D2-R15 · 证据检查器与只读并排（P1）

**必须行为：**默认仍用同pane Reader；足够宽时可显式打开仅用于当前来源的可关闭证据检查器，最小主区600、检查器360逻辑宽，不足时改为同pane阅读层。非永久导航，不引入项目侧栏。

**边界与实现：**两区显示同Session来源，不新开PTY；检查器不挂写sink、不因选源改执行目标。普通Block显式布局变化可走resize；TUI期间检查器采用不改底层几何的overlay/独立只读层，不悄悄压缩TUI。

**验收：**`D2-T15`。来源正确、可退出、位置保存；TUI几何未因只读覆盖而改；无observer写。

### D2-R16 · Raw/TUI/密码输入边界（P0）

**必须行为：**原始终端中键盘、粘贴、鼠标和应用光标模式使用已有TerminalInputController。进入密码/续行/交互状态时Composer暂停且保留占位高度；shell可信ready后只在用户仍聚焦原pane时恢复编辑。

**边界与实现：**不得通过Shell输出文本猜密码或prompt并强行接管；shell不支持/未协商时“仅编辑，可复制”准确呈现。特殊图形、mouse mode与未归属输出保持保守回退。

**验收：**`D2-T16`。不会把密码/REPL输入路由给AI；ready不抢其他pane；手动恢复Blocks清楚。
