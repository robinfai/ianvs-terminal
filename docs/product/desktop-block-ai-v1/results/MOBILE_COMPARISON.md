C8 完整 gate 已归档，并保留 verify9 的 SDK cache 沙箱失败与 verify10 的真实重跑结果。可继续执行的工作是：USB 已恢复；待镜像解锁后，继续已获授权的 cloud 配置/私钥导入，再在明确手机构建 SHA 上测试 SSH 并采集完整真实 API/原生提交链；依次做直接 IME/触控/旋转、VoiceOver、5 时点断网、锁屏/后台/进程死亡、真 TUI/密码、大输出与无换行、性能；完成 macOS API/ACP 两条路径及数据回滚；归档与新 C 对应的公开证据。涉及用户必须亲自完成的系统认证/物理操作时，说明具体动作即可，不重复询问已授权的测试端点和安装范围。

物理 iPad、外接显示器与旧支持系统是具体环境缺口；用户已确认暂缺前两项设备。可以先完成其它独立验收，再安排可用设备/环境；在取得它们以前分别保留 `blocked` 或 `implemented_unverified`。保活间隔、模拟器图或 fake PTY 回归都不能解除这些证据要求。
