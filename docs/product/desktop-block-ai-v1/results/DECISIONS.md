# 本轮交互决策

2026-10-10。具体合同和验收场景在 [v1.1 修订](../16_REVISION_1_1.md)。这些决定不代表已经实现或通过。

| 编号 | 决策 | 理由 |
|---|---|---|
| DR-01 | 继承已实现三档审核及旧配置迁移 | 避免重构退回多数操作人工确认；API／ACP分别验收 |
| DR-02 | 已知未提交的旧提案撤销；未知时暂存补充，明确继续才发送 | 保留新意图并避免不确定提交后重发 |
| DR-03 | Esc／收起进入只读观察；暂停、接管、中断各自明确 | 关闭视图不隐含转移写权限；等待不按墙钟到期 |
| DR-04 | 人工编辑保存只生成待明确执行的新版本 | 保存不等于执行；保留失效旧文本供追溯 |
| DR-05 | 可结束未知任务的跟进，并保持旧记录只读 | 用户有出口，原未知事实不被清空或伪装成功 |
| DR-06 | 静态参考保留，生产 token 独立验收 | 原静态浅色辅助文字低于文档自定对比度目标 |

实施先修输入、审批与恢复，再补并排检查器、视觉状态和原生验收；分期不删 64 条范围。不能把模拟回归、截图或某一种后端通过当成所有平台／后端已通过。
