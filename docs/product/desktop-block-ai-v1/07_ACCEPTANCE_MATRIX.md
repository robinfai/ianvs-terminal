需求：`D1-R01` · 严重度 P1

**Given**：隔离开发App、明确会话与已准备的对应fixture；从基线状态开始。

**When**：用隔离 Profile 打开两个 tab；在活动 tab 进入和返回 AI；核对 session id、PID/PTY identity、顶部层数与底部状态栏。

**Then**：进入/返回不重建 Shell；目标始终可见；任务区域关闭后原草稿和终端仍在。
