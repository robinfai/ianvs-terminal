# Engineering Retrospectives

这个目录保存跨多轮对话、实现、验证和返工形成的工程复盘。它不是当前任务状态的权威来源；任务状态仍以 `docs/tasks/`、验证记录和代码为准。

复盘文档用于后续 agent 快速理解：

- 当时的目标、约束和成功标准。
- 用户反馈、截图、录制和测试如何推动定位。
- 哪些假设被证实或证伪。
- 最终修复、验证证据和剩余风险。
- 下一次类似问题应该怎样更快收敛。
