# Trail 0.1.0 测试版

首个 Developer ID 签名、公证发布流程的测试版本，用于收集 macOS 使用反馈。

- 本地终端与 SSH 工作区、终端会话管理和 AI 辅助交互。
- macOS universal ZIP，包含 Apple silicon 与 Intel 架构，最低 macOS 14。
- Developer ID 签名、Apple 公证、装订票据和 SHA256 文件校验。

下载 `Trail-0.1.0-macOS-universal.zip`，解压后将 Trail.app 拖到 Applications。
此版本为 Pre-release，不替换历史 v1.0.0 的 Latest 标记；版本号是本次测试发布编号。
测试版更新源固定在本次 release，后续正式版需手动安装一次。

已知限制：此发布流程尚未配置同步 Keychain 所需的 provisioning profile，
跨设备主密钥自动同步及依赖它的远程数据服务恢复不可用；本地终端、SSH
和使用本机 Keychain 的 SSH/AI 凭据存储不依赖该同步权限。

请对重要配置保留备份。反馈请附 macOS 版本、CPU 架构、复现步骤和脱敏日志。
构建流程验证不等于所有支持的 macOS 版本均经过实际运行验收。
