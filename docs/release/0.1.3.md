# Trail 0.1.3 测试版

- 优化 macOS AI 工作区布局，统一细线图标、输入框边框与按钮样式；聚焦时仅轻微加深边框。
- 固定终端 / AI 模式切换，保留草稿并恢复普通终端输入焦点。
- AI 模式下终端列数跟随聊天输出区宽度，窗口缩放同步调整，切回普通终端恢复全宽。
- 输入框支持 ACP 与 LLM API 模型列表，超过 10 个模型时显示搜索。
- macOS 设置继续使用弹窗，AI 保存行为与其他设置一致。
- 包含主线的分阶段 AI 连接检查、SSH 启动修复及 DMG 安装包支持。

沿用 0.1.x 测试更新通道。支持 macOS 14 起的 Apple silicon / Intel；发行包由 CI 执行 Developer ID 签名、公证及 Sparkle 更新签名验证。
