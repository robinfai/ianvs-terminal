# OSC support matrix

Status reflects product behavior and repository evidence on 2026-07-12. A
dispatcher arm, enum variant, or parser function by itself is not evidence of
product support.

Evidence labels:

- **covered**: an automated assertion exercises the stated behavior.
- **gap**: implementation exists, but the named layer has no targeted assertion.
- **N/A**: that layer is intentionally absent (normally for a no-op/deferred protocol).
- **pending**: the manual GUI or reference-terminal run has not been executed.

`Host smoke` distinguishes real-PTY tests from the final GUI/reference-terminal
acceptance. The latter remains pending unless explicitly stated; this matrix does
not infer interoperability from `$TERM` or from Ianvs-only tests.

## Deferred phases and acceptance boundary

- **Phase 8 / OSC 99** safe subset is implemented. Shell-provided buttons,
  activation callbacks, close reports, sound, icon transfer, urgency and command
  actions remain unsupported and unauthorized.
- **Phase 9 / OSC 3008** typed metadata is implemented. It intentionally has no
  visual UI and cannot authorize host behavior.
- **Phase 11 / OSC 22** pointer shapes are appearance-only; they cannot move the
  host pointer, capture input or authorize host actions.
- **Phase 12 / OSC 66** sized text is appearance-only; fixed/natural widths,
  scale, alignment, grid edits, scrollback, resize and rendering are covered.
- **Phase 13 / OSC 72** implements a user-driven macOS drop-target subset.
  Outgoing drags, remote URI entry reads and directory traversal remain deferred
  as separate host-action/file-authority capabilities.
- **Phase 14 / OSC 1337 metadata** implements SetMark,
  ShellIntegrationVersion and an accurate logical ReportCellSize response.
  Upload/download, focus, URL, profile and custom actions remain separate and
  unauthorized.
- **Phase 15 / dynamic cursor shape** implements OSC 1337 CursorShape and
  exports existing DECSCUSR shape/blink state through additive cursor fields.
  It also removes the prior DECSCUSR warning-bell-volume side effect.
- Unsupported/deferred OSC must remain a bounded no-op without product-state
  mutation. Host actions remain policy-gated, JSON compatibility remains additive,
  and protobuf tags must not be reused.
- Phase 11 final `@电脑` GUI acceptance passed on a cold-launched standalone
  Debug app with real-PTY set/reset markers, command menu, Profiles, second-tab
  input/output and `SHELL ACTIVE` semantics. Reference-terminal probes remain
  **pending** until an actual run records the app, version, intermediary
  (tmux/screen if any), probe bytes and observed consume, echo, reply, metadata
  and host-action behavior.
- Phase 12 final `@电脑` GUI acceptance passed on a cold-launched standalone
  Debug app with live scaled OSC 66 rendering, protocol-defined EL erasure,
  clear/reset, command menu, Profiles, second-tab input/output and
  `SHELL ACTIVE` semantics.
- Phase 13 final `@电脑` acceptance visibly covered the production real-child
  query and exact `drop=1:offer=0` response. Finder move/drop/data and native
  operation mapping are covered by the green product, real-PTY and RunnerTests
  gates because Computer Use cannot hold a cross-app drag across the
  asynchronous child negotiation round trip.
