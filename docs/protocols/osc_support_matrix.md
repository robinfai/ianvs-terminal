# OSC support matrix

This matrix maps current protocol behavior to implementation and automated coverage.
A parser function alone does not establish product support, and a test source does not prove
that a particular host run passed.

- **covered**: automated assertions exercise the named behavior.
- **gap**: implementation exists without a targeted assertion at that layer.
- **N/A**: the layer is intentionally absent.
