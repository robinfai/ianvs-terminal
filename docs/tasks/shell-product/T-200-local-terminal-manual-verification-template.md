# T-200 Local terminal manual verification template

## Milestone

P0-P5 verification and closure

## Intent

Provide a structured fill-in template for the manual/integration verification
gates required by T-169.

## Scope

- Define metadata required for manual verification.
- Define evidence rows for local shell smoke.
- Define evidence rows for paste/focus safety.
- Define evidence rows for multipane behavior.
- Define evidence rows for notification behavior.
- Define evidence rows for hotkey-window failure paths.
- Map filled template observations into verification evidence records.

## Deliverables

- `docs/LOCAL_TERMINAL_MANUAL_VERIFICATION_TEMPLATE_2026-05.md`

## Acceptance criteria

- Every manual gate from the verification command plan has a fill-in evidence
  section.
- The template states that it is not evidence until filled with real results.
- The template explains how to convert results into verification evidence
  records.

## Status

Created. The template documents manual verification evidence requirements; it
does not execute them.
