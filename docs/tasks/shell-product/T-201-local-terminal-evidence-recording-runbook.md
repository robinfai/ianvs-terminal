# T-201 Local terminal evidence recording runbook

## Milestone

P0-P5 verification and closure

## Intent

Document the operational process for converting real production wiring,
command output, and manual verification results into final completion evidence.

## Scope

- Define prerequisites for evidence recording.
- Define the step-by-step recording sequence.
- Map verification gates to record sources.
- Define failure handling for failed, skipped, and pending gates.
- Define the final closure check.

## Deliverables

- `docs/LOCAL_TERMINAL_EVIDENCE_RECORDING_RUNBOOK_2026-05.md`

## Acceptance criteria

- The runbook explains how to build final evidence from real wiring and
  verification output.
- Failed, skipped, and pending gates remain blockers.
- The runbook states that no evidence has been recorded in this session.

## Status

Created. The runbook documents evidence recording; it does not execute
verification.
