# 当前任务规则

本目录只保存进行中的任务及 [模板](TEMPLATE.md)。完成后将当前行为和边界合入对应模块规范，
将剩余问题合入 [KNOWN_ISSUES](../KNOWN_ISSUES.md)，然后删除任务文档。
不保存已完成任务、历史验收日志或文档备份。

新任务从模板开始，使用清晰的主题文件名；无需延续历史流水编号。
每个任务只解决一个可验证目标，明确范围、验收条件和相关测试命令。
验收遵循 [ACCEPTANCE](../ACCEPTANCE.md)，命令以 [TESTING](../TESTING.md) 为准。
模块规范应链接当前源码、测试与可执行脚本；运行产物留在 `build/` 或临时目录，
不复制到 `docs/`。尚未完成的检查必须明确记录，不能用历史通过结果代替当前验证。
