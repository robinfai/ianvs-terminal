### 定案

核对后接受你的修正：卡间距 8pt 与 current 底色 alpha .35 不再动；勾选+淡蓝底是“当前会话”的语义双编码，非冗余；底部会话数无额外边框、Divider(height:1) 保留。以下只按你给的取舍收敛，最多 5 项。

1. **P1｜“最近会话”改连续轻行+内缩细分隔线**
   移除每行厚底卡（surface 填充+12 圆角），改为无底色行；分隔线内缩，对齐标题文字左缘（左右各 16，线不穿到卡片外边）。行内垂直 padding 12；有摘要项自然高，副标题 13–14pt、最多两行。收益：扫读节奏连续，与“当前会话”单张淡蓝卡形成层级对比；风险：行内点击热区须至少 44pt 高，无摘要行需靠 padding 而非卡片暗示可点。
2. **P1｜“新会话”无摘要行**
   不添加虚假摘要、不删空会话；按内容自然高、最小 56pt。草稿仅在确实存在草稿时标记，无草稿即无标记。收益：不打断列表节奏也不伪造信息；风险：56pt 与有摘要行高差明显，需靠分隔线维持连续感。
3. **P2｜顶区**
   标题 16pt/600 单行（2 行时截断受限，不换行撑高）；搜索框高 44、圆角 10–12（与卡片圆角一致）、左右 16–20 内边距；标题与搜索框、搜索框与首个分组标题间距各 20–24。收益：顶区呼吸感与圆角统一；风险：下移约 8pt，首屏可见行数略减。
4. **P2｜分组间距与分组标题**
   “当前会话”“最近会话”分组标题距上方内容 20–24，距下方第一行 8–12；分组标题沿用弱化次级色。收益：两个语义区的分界靠空间而非底色；风险：与连续行分隔线视觉密度叠加，需确认不显碎。
5. **P2｜底部**
   固定底栏保留，Divider(height:1) 保留，“5 个会话”维持弱化样式，不加额外边框。深色下需确认该 1pt 线在深底可见（截图判断不了对比度，仅提示验证）。收益：归属明确且不加重；风险：低。

### 明确不改
