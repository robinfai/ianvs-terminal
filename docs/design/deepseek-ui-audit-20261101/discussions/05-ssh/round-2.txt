定案如下（数值为待落地验证的建议值）。

1. P1 全端输入与分组层级
- 统一输入/下拉/公私钥行：1pt 弱描边 + 浅 surface 底，圆角 8pt；保留私钥行整行可点击边界，不改为无边框。
- 标签文字用 secondary 色，分组标题（连接/身份验证）用 primary 且上间距 24pt；字段间距 16pt，说明距控件 6–8pt。桌面控件高 28–32pt，移动 44–48pt。
- 收益：一眼分清字段名、控件、注解；风险：弱 surface 在深色下需复核可读性。

2. P1 “密码回退/私钥口令”操作图标
- 眼睛/删除视觉 18–20pt，热区至少 44×44pt（桌面按指针目标可 28–32）；图标之间留白不得当作热区，热区间实际间隔 ≥12pt 或明确分区。
- 仅在有可清空内容时显示删除图标；无内容时隐藏，避免空白操作噪声。安全说明保留，仅当同一解释重复出现才收束。

3. P2 iOS 底部“连接”按钮
- 高度 48pt，圆角与输入框一致（8pt）；与最后控件间距 24pt。下方留白按既有底部输入占位处理，不视为缺陷。

4. P2 macOS 表单
- 保持左标签列 + 右侧控件，窄窗口自适应；保留显式“端口 22”，不并入更多设置；底部保存/取消/连接不动。私钥行保留“替换/垃圾桶”操作，弱化描边、不弱化文案。

明确不改：字段与认证流程、安全说明、保存加密语义、AI 执行授权、桌面/手机的信息组织差异（端口位置、更多连接设置），以及手机固定字号。

验收条件：
1. 浅/深色下，分组标题强于标签、标签强于说明，弱描边不与强调按钮抢焦点；眼睛/删除仅在有效状态出现且热区不低于 44pt（移动）。
2. 桌面 1280×900 与窄窗口下左标签列不压缩控件；手机高度 48pt 按钮不遮挡最后字段，字段间距 16、分组 24、说明 6–8 在两端一致落地。
