# Trail iOS 设计对比网页

本页展示 Trail 移动端功能层级与紧凑尺度的实际模拟器截图，不连接生产服务。

- 当前预览：http://127.0.0.1:4178/#density-ssh
- 51 个场景、96 处图片引用、22 项功能取舍；含本轮 13 个紧凑尺度场景及上一轮 38 个场景。
- 默认展示紧凑 SSH 表单；支持场景切换、前后并排、只看调整后、图片放大、选定设计稿查看与原图打开。
- 图片复制自上一层的 `before/`、`after/` 和 `../../ios-density-20260911/after/`，保留原始字节。
- 不同交互状态的对比已显式标注；本轮以收紧前实现为基线，上一轮记录单独分组。
- 详细验证与适用范围见 `public/density-review-notes.md`。

启动：先运行 `npm ci`，再运行 `npm run dev -- --host 127.0.0.1 --port 4178 --strictPort`。
构建验证：`npm run build`。网页尚未发布到公网。
