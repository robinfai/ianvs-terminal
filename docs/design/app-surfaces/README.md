# App surface visual acceptance

This folder covers the desktop shell, command palette, and Profiles sheet.

- `round-1-imagegen/` contains the first ImageGen annotations made from the
  available manual screenshots.
- `current/` contains deterministic 1280 × 800 dark-mode goldens generated by
  `example/test/design/app_surface_visual_capture_test.dart`.
- `final-imagegen/` contains the ImageGen acceptance pass over the original
  August 2026 goldens.

The current September 2026 captures preserve the accepted command-palette row
spacing, keyboard clearance, Profile summary hierarchy, and pointer-oriented
overlay placement. They also reflect the Trail rename, the reduced supported
action set, the Replay, search, and settings toolbar entry points, and the
macOS-aligned dark theme. Visual review found no clipping, overflow, unintended
hidden action, or executable P1/P2 issue in the three captured states.

Regenerate the current captures with:

```sh
cd example
flutter test --update-goldens test/design/app_surface_visual_capture_test.dart
```
