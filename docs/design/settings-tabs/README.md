# Settings tabs design iterations

This folder records three evidence-based design iterations for the macOS
“Defaults & appearance” settings surface.

Each round keeps the same 1440 × 1024 light-mode viewport and the same Chinese
content state. Every round contains:

- one screenshot for each of the five settings tabs;
- ImageGen design targets with numbered difference markers;
- a written mapping from the markers to concrete implementation changes;
- a post-implementation comparison and QA result.

`current/` is the reproducible golden output generated by
`example/test/design/settings_tab_visual_capture_test.dart`.

Round 1 is captured in `round-1-imagegen/`, `round-1-implementation/`, and
`round-1-comparison/`. Its remaining P1/P2 findings are the input to Round 2.

Round 2 is captured in `round-2-imagegen/`, `round-2-implementation/`, and
`round-2-comparison/`. Its remaining P2/P3 polish items are the input to the
final round.

Round 3 is captured in `round-3-imagegen/`, `round-3-implementation/`, and
`round-3-comparison/`. It closes the remaining action-economy, column-scanning,
recommendation-state, responsive-copy, and micro-alignment findings.

The final implementation is also copied to `current/`. A consolidated QA
handoff is available at the repository root in `design-qa.md`.
