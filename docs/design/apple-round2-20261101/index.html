场景结构调整边界与进度
Mac 常规 / 外观固定宽度内容区、紧凑标签和控件；外观选项与实际预览分区，减少重复标题当前已出代表图；不修改终端预览的渲染组件
快捷键按实际分类分组；动作名左、快捷键右；搜索与空结果对齐；改键冲突就近提示保留所有动作和恢复默认，不新增快捷键
iOS 设置导航 / 安全入口只显示当前摘要，策略详情页展示所有选项与影响主页面代表图已出；拒绝、按连接设置、允许、询问均保留
AI 连接连接、审批策略、连接测试三段；长 URL、密钥、模型真实输入代表图已出；失败可重试，不自动提交命令
成功 / 失败 / 加载成功轻量 2 秒后消失；失败保留原因与恢复动作；加载只标正在发生的操作无意义普通提示移除，不把错误伪装成空列表
账号 / Apple / 历史关联登录后身份与服务信息独立组；注销为独立动作；关联页面先解释保留历史数据，再输入凭据登录后隐藏登录方式；关联失败保留输入；不自动合并
回放列表 / 详情统一分组列表，名称与真实元数据分级；播放器与文件详情分区；可恢复的空态与错误不修改终端回放渲染，不造时间/大小/在线状态
导入 / 密码认证任务标题与来源先行；输入、错误、动作各有层级；敏感字段掩码保留取消、清除能力与原有提交校验
主机指纹 / 权限确认具体主机、完整指纹、风险说明按顺序；拒绝优先；危险变化持续可见完整指纹可复制；不因美学省略或自动信任
Profile 编辑标识、连接或启动参数、外观、按键、自动化、高级设置按既有能力分组只重组编辑器外壳，不改配置语义与终端组件
文件与会话附属界面完善工具栏、路径、行菜单、断开/无权限/操作失败状态；上下文不丢失在上一轮基础上深化，不造不存在的文件元数据
terminal 独立组件本轮明确排除深入改动输出、ANSI、光标、选择、绘制、滚动内核及回放渲染保持

统一参数

iOS：17/15 pt 固定字号、20 pt 外边距、16 pt 内边距、控件触控至少44 pt。Mac：13–14 pt 字体、32 pt 控件、110 pt 标签列、210 pt 侧栏、正文限宽560–640 pt。这些是产品设计目标，不是 Apple 强制数值。

保存与取消的位置稳定；只有改动时显示“有未保存的更改”。成功不残留常驻胶囊；失败就近显示原因与恢复动作。深色遵循同一层级，后续实现时逐页截图验收。
