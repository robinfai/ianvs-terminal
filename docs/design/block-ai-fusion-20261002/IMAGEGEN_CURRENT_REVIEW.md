# 当前 AI 对话与证据页视觉迭代

2026-10-03 至 2026-10-04，`composer` 工作区。此次以当前生产 UI、真实 ACP 对话和原生终端截图进行九轮内置 imagegen 复核。可确认的问题均已处理；第七轮的四个手机审阅／快照场景，以及第九轮的三个实际提示状态，均返回“未发现可确认的视觉问题”。这只代表所示场景的本轮审查结论，不是所有输入和设备上绝无缺陷的保证。

## 实际改动

- 证据阅读页避开 macOS 顶部 44pt 原生窗口按钮及拖动区域，使用主窗口同一高度常量；与系统 SafeArea 取最大值，手机不增加该间距。真实 OS 鼠标已能点击返回，再次进入和返回仍保留任务及唯一命令块。修复前后的运行记录见 [证据导航目录](../../ai/evidence/evidence-navigation-20261003/)。
- 提案明确标出目的、执行目标、完整目录与命令／终端按键；目录独占一行，保留审批前核对完整路径的能力。
- 宽阅读页给查找和更多操作添加文字；窄页保留图标。新增清空查找文字，清空后继续编辑，阅读位置与选区不变。
- 输出快照区分命令、目录、来源、行范围与退出码，非零退出码有明确文字和强调。原输出没有改写。
- 窄屏状态使用省略号及完整提示，避免半截语句被直接裁切。

保留平面单列、细分隔线、独立完整审阅页和单一主操作的审美取舍，没有增加聊天侧栏、装饰卡片或额外确认层。

## 运行验证

- **真实 ACP `gpt-5.6-sol`**：在隔离演示目录提出 `cat status.txt`，人工批准一次，原生只产生一条退出码 0 的命令块，文件未改动；回答引用原输出并区分文件声明与服务实际状态；证据页可往返。[结果与对比度／点击范围测量](evidence/imagegen-current/real-acp/result.json)。此场景使用每次确认模式，不将它宣称为真实模型智能审核的普遍安全性证明。
- **应用组件 104 项通过**：工作区及证据导航，含浅深色、手机固定字号、桌面 2 倍字号、高对比、减少动态效果、任务／草稿／选区、恢复提示及真实悬停 Tooltip。
- **共享终端 22 项通过**：主题、阅读工具、手机布局；新增清空查找保持原位置与选区的检查。
- **原生应用 5 项通过**：单次执行、原始证据、多块上下文、分页查找、静默／分批输出、回看返回、配置恢复、Vim 交接和四个手机尺寸的生产组件预览。
- **原生阅读器 4 种尺寸通过**，另有小屏长按提示专项通过。固定字号、横向滚动行号固定、选区和搜索标记保持；均在 macOS 原生渲染器中运行，不是 iPhone 真机。
- 静态分析、格式和发布镜像检查通过；日志及源文件哈希在 [本轮证据](evidence/imagegen-current/manifest.json)。

原生回归曾暴露两个测试前提过时的问题，失败日志保留：测试模型在命令退出前提出下一条动作，随后被正常的终端状态保护撤销；现改为 shell 就绪后提出新动作。另一个用例在删除配置后仍预期旧的每次确认设置，现按当前新连接默认智能审核核对。没有削弱生产代码的审批保护。
