## 打开与复现

双击 [index.html](index.html) 可直接浏览，资源均为相对路径，不依赖外部脚本或网络。也可在本目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

随后打开 http://127.0.0.1:8766/ 。服务仅监听本机；此目录只包含设计交付材料。
