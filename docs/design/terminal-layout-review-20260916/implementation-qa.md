# 终端布局实现与验证

初版日期：2026-09-16。基线：`e2f4efd0`。已按预期图实现，并按最终要求移除“模式”和协议特性状态展示。2026-09-17 根据使用反馈恢复非活动窗格降低亮度的设计，下方组件截图已更新。

## 已实现

- 桌面标签靠左排列，等宽且最大 240 逻辑像素；新增按钮紧随标签，标签溢出时仍可用。
- 多窗格标签显示一次窗格数量。标签关闭按钮位于右侧，鼠标悬停或键盘聚焦时出现。
- 窗格标题改为简短编号和真实终端标题；编号保留完整位置和活动状态的无障碍说明。
- 活动窗格显示分屏、缩放操作；每个窗格都有“更多”，窄窗格也能通过菜单访问操作。
- 窗格菜单绑定打开它的具体会话，切换焦点后仍操作原目标；关闭入口收进菜单。
- 保留非活动窗格遮暗，并使用焦点边框标记活动窗格。遮暗沿用主题原有强度，不拦截点击；悬停链接时保留原来的临时提亮行为。边框尺寸保持一致，切换焦点不会改变终端可用尺寸。
- 移除备用屏幕、鼠标上报、括号粘贴、MIME 粘贴、焦点上报、扩展键盘、同步输出等协议状态标记。底层协议仍生效。
- 保留只读、远程、进度、通知和会话徽标；提示过多时可水平滚动，避免挤出标签边界。
- 继续使用现有主题、分隔线、拖拽和动态标题逻辑，不重绘或替换 shell 提示符。
