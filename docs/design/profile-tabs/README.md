# Profile tabs design iterations

This folder records three ImageGen-assisted design iterations and one final
acceptance pass for all seven sections of the macOS Profile editor.

The clean baselines are reproducible golden captures generated by
`example/test/design/profile_tab_visual_capture_test.dart` at 1440 x 1024,
1x density, light appearance, Simplified Chinese, and the macOS theme.

The annotated images are design-review targets rather than production image
assets. Production UI should keep real localized strings, theme tokens,
keyboard focus behavior, semantics, and responsive scrolling instead of
copying generated pixels or generated text literally.

## Iteration intent

- Round 1 restructures each section for clearer hierarchy, lower visual
  density, and more economical use of the desktop dialog.
- Round 2 changes the remaining implementation-risk details: false or ambiguous
  affordances, mixed-language labels, unstable action columns, redundant
  hierarchy, and accidental clipping.
- Round 3 validates scrollbar visibility, footer separation, control density,
  unit alignment, and explicit enabled states against the implementation.
- `final-imagegen/` contains the acceptance pass. No executable P1/P2 finding
  remains across the seven sections.

The related five-section settings workflow already lives in
`../settings-tabs/` and contains three complete ImageGen/design/implementation
rounds, which exceeds the requested two-round coverage.

## Reproduce the baselines

```sh
cd example
flutter test --update-goldens test/design/profile_tab_visual_capture_test.dart
```
