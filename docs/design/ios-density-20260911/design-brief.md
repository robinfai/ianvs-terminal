## 拟议标尺（默认文字大小）

| 项目 | 当前或问题 | 建议目标 |
|---|---|---|
| 页面导航标题 | 22pt；部分表单还有重复副标题 | 17–18pt、44pt导航栏，移除重复副标题 |
| 正文与输入 | 17pt为主 | 输入/普通列表16–17pt，长篇说明保持17pt |
| 标签与辅助说明 | 与主要内容视觉接近 | 标签13–15pt、辅助13pt，明确角色 |
| 输入框 | 48pt下限，padding叠加后约50pt | 44–48pt，按文字大小自然增高 |
| 设置单行入口 | 最小56pt | 常规48pt；少量简单行可44pt |
| 图标按钮 | 常用图标22pt、触控48pt | 视觉18–20pt，触控不小于44×44pt |
| 回放播放键 | 56pt底色、32pt图标 | 44–48pt底色、24pt图标 |
| 回放时间文字 | 15pt | 13pt，等宽数字 |
| 回放控制区 | Slider/时间/操作三行叠加约137pt | 目标100–108pt（不含安全区）；进度与时间合并区域，操作行44–48pt |
| 留白 | 标签/输入/分组多层叠加 | 标签到字段4pt，字段间12pt，组间20pt |

所有尺寸均为待验证的设计目标，不是已落地或已测量的新版本表现。大字体下允许换行、纵向重排、行高增长，不用固定maxHeight截断，也不锁定textScale。

## 三个独立视觉方向

- 轻量收紧：保留上下标签和描边输入，统一更小标题、字段、间距；改动范围最小。
- 原生行式：名称/主机/用户/端口使用iOS同排标签和值的分组行；减少垂直重复标签与描边，主要动作在导航栏。
- 常用项优先：主机、用户、认证与密码常驻；名称、端口与高级参数进入明确的“更多连接设置”，显示端口22摘要。

三张图均为同一SSH任务的概念样稿，不能替代真实Flutter渲染/触控/Dynamic Type验证。图的显示顺序决定用户选择编号；不要根据此文档的列举顺序推断编号。

## 选定方向后的范围

1. 先将选中结构应用于SSH、回放和设置代表页，用同一尺寸标尺检查。
2. 共享设计系统需评审“视觉密度”与“触控能力”分离：不能为获得32pt桌面控件而把iOS切换为compact，当前usesTouchControlDensity还影响移动导航分支。
3. 如需共享新增能力，按用户此前授权向ianvs_design项目提交明确需求，由该项目自行评审、实现和发布；所选方案的通用紧凑触控能力已由共享库评审并发布；宿主按正式版本接入。
4. 375/402pt竖屏、横屏、浅深色、系统放大文字、键盘弹出与错误提示需真实渲染验证。用户终端字号独立于App UI字号。

## Apple参考

- https://developer.apple.com/design/human-interface-guidelines/buttons ：按钮应有足够空间，通用建议hit region至少44×44pt。本次采用44pt作为设计下限。
- https://developer.apple.com/design/human-interface-guidelines/typography ：语义文字层级与字号适配。
- https://developer.apple.com/design/human-interface-guidelines/accessibility ：文字放大与触控可达。

Apple参考支持可读性与触控约束；16pt字段、48pt列表、100–108pt回放区域是本项目设计建议，不声称是Apple强制尺寸。
