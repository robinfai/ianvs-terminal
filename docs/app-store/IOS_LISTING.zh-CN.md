## 宣传文本

在 iPhone 和 iPad 上使用沙盒终端、管理 SSH 连接，并把常用命令行工作流随身携带。无需注册 Ianvs 账号即可开始使用。

## 描述

Ianvs Terminal 是面向开发者和服务器管理员的移动终端工作台。

无需注册账号，你可以直接进入 iOS 沙盒终端；需要访问自己的服务器时，也可以创建 SSH 连接。远程数据服务为可选功能，仅连接到你自行配置的服务。

主要功能：

- iOS 沙盒内的本地终端
- SSH 主机与连接配置
- 标签页和分屏工作区
- 终端内容搜索、选择与复制
- 会话记录与本地配置保存
- 可选的远程数据同步
- 凭据保存在系统钥匙串中

Ianvs Terminal 不包含广告、第三方分析或跨应用跟踪。

## App Review 备注

Ianvs Terminal 无需账号即可审核：

1. 首次启动后，在 “Choose your data mode” 页面选择 “Use local terminal only”。
2. 应用会进入 iOS 沙盒终端，不需要远程服务或测试账号。
3. SSH 和远程 HTTP API 均为用户主动配置的可选功能；应用没有默认连接的开发者服务器。

应用使用 SSH 和本地凭据加密能力。出口合规问卷应按实际密码学实现填写，不应声明为“不使用加密”。

## App 隐私标签建议

在当前代码和“开发者不运营默认后端”的前提下，选择“开发者不从此 App 收集数据”。App 会在设备上处理终端内容、SSH 配置和凭据，并按用户指示连接用户自己的主机或 API；这些数据不发送给 Ianvs Terminal 开发者。

如果发布方将来运营默认同步服务、加入分析/崩溃上报或提供客服数据上传，必须在提交前重新评估隐私标签和隐私政策。
