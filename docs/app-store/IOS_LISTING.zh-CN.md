## 宣传文本

在 iPhone 和 iPad 上连接 SSH 主机，并把常用远程命令行工作流随身携带。无需注册 Ianvs 账号即可开始使用。

## 描述

Ianvs Terminal 是面向开发者和服务器管理员的移动终端工作台。

无需注册 Ianvs 账号或配置数据服务，你可以创建不保存的一次性 SSH 连接，访问自己的服务器。若要保存自定义 SSH 配置或跨设备同步，可选择连接由你自行管理的远程数据服务。

主要功能：

- 一次性 SSH 连接
- 通过可选远程数据服务保存 SSH 配置
- 标签页和分屏工作区
- 终端内容搜索、选择与复制
- 会话记录与应用偏好本地保存
- 可选的远程数据同步
- 凭据保存在系统钥匙串中

Ianvs Terminal 不包含广告、第三方分析或跨应用跟踪。

## App Review 备注

Ianvs Terminal 无需 Ianvs 账号即可进入主界面和创建一次性 SSH 连接：

1. 首次启动后，在 “Choose your data mode” 页面选择 “Continue without data service”。
2. 在主界面选择 “New SSH Connection”，即可填写用户自行管理的 SSH 主机并进行一次性连接；该配置不会保存。
3. 远程 HTTP API 仅用于保存 SSH 配置和跨设备同步，完全由用户主动配置；应用没有默认连接的开发者服务器。

应用使用 SSH 和本地凭据加密能力。出口合规问卷应按实际密码学实现填写，不应声明为“不使用加密”。

## App 隐私标签建议

在当前代码和“开发者不运营默认后端”的前提下，选择“开发者不从此 App 收集数据”。App 会在设备上处理终端内容、SSH 配置和凭据，并按用户指示连接用户自己的主机或 API；这些数据不发送给 Ianvs Terminal 开发者。

如果发布方将来运营默认同步服务、加入分析/崩溃上报或提供客服数据上传，必须在提交前重新评估隐私标签和隐私政策。
