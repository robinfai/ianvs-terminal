# 2026-10-29 移动端首轮体验修复

本轮独立于已合并的 PR #23，基于 main `b83cdeba2efccc11d063b274046ff6433dfd34fb`。
黑盒问题由 iPhone 18 Pro / iOS 27.0 隔离模拟器的 `f1779096` 构建复现。

| 问题 | 原因与调整 | 回归 |
| --- | --- | --- |
| M04 审批目标后出现 root，易误认为执行用户 | `root` 实为内部 Shell contextId，不是实际执行用户；审批卡不再展示该内部 ID。SSH 目标使用当前连接链末端的 user@host:port；本地保留会话名，执行 session/context 绑定不变 | SSH 目标显示单测；移动完整审批不泄露 root 上下文；AI 上下文、审批作用域、输入恢复回归 |
| M03 旧 SSH 失败污染新成功会话 | 失败细节保存在来源窗格；激活其他连接时清除该来源的全局提示。后台 SSH 失败不覆盖当前会话的全局提示；不清除无关运行错误 | 新连接、切换、后台失败、关闭来源、无关错误保护 |
| M02 AI 空白保存看似无响应 | LLM 地址/API Key/模型在字段旁显示明确校验信息；保存及测试连接均聚焦并滚动到首个错误，校验不通过时不写配置、不发请求 | iOS/Android 中文窄屏空白保存、逐字段焦点与可见提示；有效配置保存回归 |
| M01 私钥必填提示英文 | 复用现有本地化“尚未选择私钥” | 中文移动 SSH 表单及已有密码/私钥必填回归 |
