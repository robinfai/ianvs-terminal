# Phase 26 review — OSC 1337 blocks — 2026-07-13

## Result

Phase 26 implements iTerm2 `Block` / `UpdateBlock` as reversible terminal-row
virtualization. Targeted parser, corpus, native real-PTY, resize/replay,
JSON/protobuf, Dart and widget checks are green. The repository-wide verifier
and final cold-launch Computer Use acceptance are also green.

## Baseline and scope

- Start SHA: `9cc7427992670294e1e8e7945d62af64fb75785e`.
- Branch: `codex/osc1337-block-folding-phase26-20260713`.
- Supported commands: `Block` start/end and `UpdateBlock` fold/unfold.
- Supported state: bounded nested primary-screen blocks, optional type/render
  metadata, completed multi-row folding and user-initiated toggles.
- Deferred: iTerm2's `attr=end;render=1` text/JSON document transformation; the
  folding phase retains the flag but does not claim the renderer.
- No file, clipboard, URL, focus, process, profile or other host authority is
  added.

## Official comparison and architecture

- Compared iTerm2 commit `2c6c17162f5fc979e0933714803f1a4a7f1fffa3`,
  including `tests/test_block_folding.sh`, `VT100Terminal.m`, screen/session
  delegates, `PTYTextView` folding and the first/last-line summary builder.
- That comparison confirmed `render=1` calls iTerm2's text-document rendering
  path. It is explicitly excluded from this folding-subset claim.
- Ianvs keeps the terminal grid authoritative and projects a folded source range
  into one display row. This avoids destructive mutation and makes unfold,
  search, selection and replay reversible.
- Frame rows carry optional inclusive source bounds. Frame blocks carry both
  viewport-relative display bounds and retained source bounds. Virtual
  scrollback, cursor mapping, search, selection, graphics and OSC 66 placements
  all consume the same projection.
- Nested/overlapping folds choose the outer stable summary. Folded content stays
  searchable and copyable from the original grid.

## Review findings and fixes

- Direct terminal width reflow originally left physical block rows stale.
  Width reflow and height shrink now invalidate marks when native transcript
  replay cannot reconstruct them; the session replay path restores exact fold
  state across narrow/wide resize round trips.
- Projected snapshots pad a short display with unmapped blank rows. Dart now
  distinguishes explicit source mapping from legacy contiguous frames, so
  padding cannot select hidden content or become a false search target.
- Fold summary truncation now uses the terminal's grapheme-aware width
  configuration, preserving the cell budget for combining marks, emoji and CJK
  text.
- Product toggles clear selection before requesting the layout transition and
  then force an immediate fresh frame.
- The first repository-wide pass found two warning-as-error Clippy readability
  findings. Both expressions were simplified and the complete verifier passed
  from the beginning on the next run.
- The first Computer Use pass exposed a nested semantics defect: the labeled
  wrapper was not actionable while its child action was unlabeled. The control
  now exports one labeled Tap action, has an automated semantics assertion, and
  was rechecked by activating that exact accessibility node after cold launch.

## Security, compatibility and rollback

IDs/types/counts are bounded, alternate-screen and VT220 inputs fail closed, and
the feature grants no host capability. Protobuf changes are additive (frame tag
31; row tags 6/7), legacy contiguous frames retain fallback behavior, and tags
are not reused. Reverting the Phase 26 implementation returns these commands to
bounded no-ops without data migration.
