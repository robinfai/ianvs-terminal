# 本地优先与可选 API 同步

日期：2026-09-09。

## 目标与实现边界

macOS、iOS 均无需配置 API 即可保存和使用 SSH。数据仓库不因 API 模式切换而更换。连接 API 是启用同步目标，停用是暂停传输，不是清空、迁移或切换本地数据。

同步覆盖 Profile（含加密 SSH 凭据）、当前终端设置以及兼容保存的偏好文档。终端布局、录制文件、API 登录凭据不在同步文档内。已退役的粘贴历史不采集、不上传、不拉取；旧数据保持原样。

## 合并规则

- 同步保存上次双方确认的完整快照，快照使用本地主密钥派生的 AES-GCM 加密，文件名是目标及资源标识的 SHA-256。SSH 密码、私钥不以明文写入同步状态文件。
- Profile 按稳定 ID、嵌套字段合并。不同新增和不同字段的修改自动合并；其余数组作为整体值处理。
- 双方同时改同一字段、删除与更新冲突时，保留本地和 API 各自数据，暂停该文档上传。设置页显示冲突字段，可选择本机或 API 冲突值；非冲突字段仍自动合并。
- 单个 Profile 的删除通过共同基线传播，防止重连复活。整个远端聚合文档消失可能是服务重置，需显式选择，不默认清空全部主机。
- API 写入携带期望 revision，冲突后重新读取，最多重试三次。远端写入成功但响应丢失时，下次对比双方快照确认，不重复产生主机。
- 同步网络请求不占用本地写锁。请求期间的新本地修改会再次合并并补传，不能被较早响应覆盖。旧编辑表单保存也通过本地版本快照合并，重叠冲突拒绝写入。
- 本地成功落盘与上次确认快照之间的差异就是持久待同步状态。进程退出或断网后重新启动，仍可继续补传；不依赖仅在内存中的队列。

## 触发与状态

启动应用、回到前台、定期重试及本地修改后触发同步，也可在设置中立即同步。拉取后更新可用 Profile 和设置，不替换或重启正在运行的终端连接。

API 配置保存后即时更换同步连接；关闭同步会停止后续请求，无需重启终端。API 配置或远端会话读取失败时，只降级同步能力，本地仓库仍可使用；主密钥错误仍需恢复，不能被当作 API 离线忽略。

新登录以规范 API 地址和用户名作为同步身份；历史会话没有用户名时使用独立兼容身份，重新登录后进入稳定账号身份。不同账号不共用基线。旧兼容身份首次切换可能需要重新解决已有冲突；不跨账号猜测删除历史。
