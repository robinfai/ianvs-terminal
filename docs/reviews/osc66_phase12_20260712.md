OSC 66 is no longer a deferred generic no-op. Ianvs now parses bounded sized
text, retains complete multicell blocks through grid operations and scrollback,
exports clipped typed placements, and renders integral and fractional sizes in
the product viewport. OSC 72 remains a separate deferred host-action protocol.

## Findings and resolution

| Finding | Resolution |
|---|---|
| Published OSC 66 sequences were discarded | Added a dedicated bounded parser and multicell state model |
| Ordinary cells could not represent multi-row text | Added per-cell block coordinates with anchor-only text storage |
| Reflow treated the anchor's block width as a wide glyph and deleted valid blocks | Reflow now moves materialized block cells individually and wraps before anchors |
| Fragment validation scanned only the visible screen | Validation now covers the unified scrollback/screen row space |
| ED 2/3 could leave fragments across the history boundary | Screen and scrollback clears erase or sanitize the complete intersecting block |
| The initial safety scan made long plain transcripts time out | Added O(1) screen/whole-grid multicell guards; the 9,000-line stress test returned to 0.36 s |
| Dart bounded text by UTF-16 length instead of wire bytes | JSON and protobuf now enforce the normative 4 KiB UTF-8 limit |
| Sized text had no product transport or renderer | Added protobuf tag 24, typed Dart placements, clipped scaled painting and multicell cursors |
| VT220 could have hidden side effects if only the frame field were gated | Existing capability denial is now asserted to preserve both text position and empty placements |

## Compatibility and rollback

The frame change is additive: JSON defaults to an empty list and protobuf uses
new tag 24. OSC 66 remains appearance-only and uses the existing appearance
policy. Reverting this phase restores bounded unsupported behavior; no host
authority is added. OSC 72 remains deferred and independently policy-gated.
