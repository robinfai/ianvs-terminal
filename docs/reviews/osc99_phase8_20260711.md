## Architecture

The vendored streaming gate classifies OSC 99 as the notification capability.
The parser retains at most 64 pending and 64 active identifiers, snapshots
in-flight assemblies, and emits the unified notification model. Native session
events preserve lifecycle and safe metadata. Dart routes typed events, the
session controller performs correlation/expiry, and macOS uses stable delivery
identifiers with explicit close and timer cancellation.

## Compatibility and security

OSC 9 and OSC 777 retain their existing constructor and `source=osc` behavior.
No protobuf change is needed because notifications use the additive JSON event
payload path. The forced JSON compatibility path remains intact.

All host actions remain policy-gated. Unsupported OSC 99 metadata is consumed
without focus, callback, sound, icon or command authority. Diagnostic records
contain hashes and sizes instead of notification content.
