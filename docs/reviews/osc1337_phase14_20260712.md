## Findings and resolution

| Finding | Resolution |
|---|---|
| `SetMark` was absent despite an existing prompt-mark navigation model | Added an OSC 1337 typed mark at the primary global cursor line and reused the bounded product mark list |
| Shell integration script version/shell were discarded | Added validated typed metadata and visible shell-health tooltip detail |
| The parser had no accurate answer for `ReportCellSize` | Routed the request to the Flutter runtime, which owns logical cell dimensions and DPR |
| A query can arrive before first layout | Queue up to 16 requests and flush one exact response per query after a committed resize |
| Physical pixel dimensions could be mislabeled as points on Retina | Preserve exact logical cell width/height in the resize metric and report those with scale |
| Modern OSC 1337 metadata could leak into VT220 | Fine-grained capability and VT220 gates fail closed; primary shell metadata is also suppressed on the alternate screen; the legacy switch retains its documented historical mapping |
