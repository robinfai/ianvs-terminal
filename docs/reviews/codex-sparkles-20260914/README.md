# Codex 星光渐隐与标题更新优化

2026-09-14。

## 修复与优化

- 终端程序显式指定的前景色保留原始渐变；主题默认文字仍使用 4.5 对比度下限，系统高对比度模式恢复全部文字的对比度保护。
- 原生标题和图标元数据更新可通过 Delta 传递，支持零脏行，不再单独触发全屏 Snapshot。
- 可打印 ASCII 使用直接宽度与裁剪路径；Unicode 字符继续使用原有逻辑。
- 桌面 Shell 将标题显示与主体布局的订阅分开。标题、系统窗口标题和分屏标题保持实时更新；菜单、快捷键执行时读取最新状态。移动端维持原订阅方式。
- 同步独立发布包 `ianvs_terminal_core` 中的对应实现与测试。

## 实际应用测量

Apple M4 Pro / macOS，Profile（Dart AOT，Rust release）。星光、动态标题和 Kitty 宠物图片完整开启，未降低动画帧率。CPU 100% 表示一个核心；数据只包含 Trail 应用进程。

| 场景 | 优化前平均 CPU | 优化后平均 CPU |
| --- | ---: | ---: |
| 完整录制回放，各三轮 | 8.16% | 7.74% |
| 真实 Codex 持续停留 | 6.51% | 6.28% |

此表只比较最后一步标题订阅隔离，基线已包含渐隐修复、原生 Delta 和 ASCII 优化。完整回放下降约 0.42 个百分点（5.1%），收益有限。真实停留只有一组样本，受宠物随机动作影响，不能据此承诺稳定降幅。

每轮完整回放先预热一个周期，再测量两个周期；忽略 `top` 初始化样本，保留十个一秒样本。每版共三十个有效回放样本、十二个真实停留样本。前后关闭 CPU profiler 与图形详细日志，采样时不运行构建或测试。逐秒样本、各轮均值及 AOT 二进制摘要见 [测量数据](performance/title-optimization-summary.json)。
