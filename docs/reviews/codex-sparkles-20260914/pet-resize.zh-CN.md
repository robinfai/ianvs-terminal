# Codex 宠物 resize 排查（2026-09-14）

用户确认错位对象是输入框旁的宠物。普通窗口 resize 后持续错位的原始报告尚未复现，不能据此宣称已经解决该报告。

## 已确认的问题与修复

`TerminalViewport` 在 build 阶段使用 controller 中的字符尺寸放置图片；文字表面在随后的 layout 阶段重新测量并更新字符尺寸。此前没有主动刷新图片布局，图片可能继续使用旧尺寸定位，直到下一次终端输出或外层重建。

对照测试先稳定初始布局，再将字体从默认尺寸调整为 20，不发送任何新终端帧。旧实现的图片停留在 x=56，正确位置应为 x=80；修复后通过。

修复在字符尺寸实际变化后的 post-frame 回调中触发一次布局刷新，且不依赖宿主是否订阅尺寸回调。同一帧的测量回调合并为一次；稳定的动画帧不会因此持续触发额外重建。图片缓存及上一张图片等待新图片解码的策略不变。
