# 会话能力中的 SSH 链路

入口：桌面命令菜单、移动端会话菜单 → 会话能力 → 顶部“连接链路”。

显示本机、连接配置中的跳板和已识别的嵌套 SSH Shell。SSH 节点显示用户、主机及端口，当前层用文字和主题色标记；返回父层时恢复原链路。转发跳板不被标成运行 Hook 的 Shell，自定义代理通道不展开未知路径。该链路描述应用已知的连接与 Shell 层级，不能还原未被跟踪的 SSH 命令或代理内部路径。

验证：session state、session controller、能力对话框及 shell screen 4 个测试文件共 134 项通过；变更范围静态分析无问题。新增断言覆盖独立跳板配置、IPv6、重复初始化不追加节点、多层返回恢复，以及对话框打开时更新当前层。

界面检查使用 390 px、2 倍字体、明暗主题及桌面视口。窄屏内容正常换行、可纵向滚动，关闭控件保持可用。
