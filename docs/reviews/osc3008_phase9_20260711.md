## Review findings and resolution

| Finding | Resolution |
|---|---|
| No OSC 3008 parser or context domain | Added all v1.0 context types and common/type-specific start/end metadata |
| No hierarchical lifecycle recovery | Added push, return/update, descendant truncation, known end, and unknown-end no-op semantics |
| Unbounded or stale state risk | Added 32-level stack, 64-byte IDs, 255-byte fields, metadata replacement, and 16 KiB ingress policy |
| Reset/replay ambiguity | RIS preserves contexts and snapshot capture/restore round-trips the hierarchy |
| No product bridge | Added `terminal_context` and `TerminalSessionContextEvent` as additive typed contracts |
| Metadata might be mistaken for authority | Product switches explicitly ignore it; no UI or host action was added |
| Diagnostics could leak command/session identity | Raw context text is replaced by counts and hashes |
| Malformed close could corrupt parents | Unknown close is ignored; ending a known ancestor closes only it and its descendants |
