## Findings and resolution

| Finding | Resolution |
|---|---|
| OSC 22 was discarded despite a published Kitty specification | Added a dedicated parser and bounded screen-local state model |
| No pointer state crossed the native/product boundary | Added optional JSON and additive protobuf tag 23 plus typed Dart decoding |
| The viewport hard-coded text/click cursors | Added exhaustive mapping for all 30 canonical shapes and grabbed fallback |
| Main and alternate screens could not isolate pointer state | Added independent 32-entry stacks retained by snapshots |
| Query and reset behavior was absent | Added current/default/grabbed/support queries, empty reset, pop and RIS clearing |
| Pointer behavior could accidentally depend on mouse reporting | Requested shapes now apply in both reporting and non-reporting modes |

## Compatibility and rollback

JSON `pointer_shape` is optional and protobuf field 23 is additive; older
frames decode to the existing text/basic fallback. The behavior is independent
of terminal text-cursor rendering and mouse-report encoding. Reverting this
phase restores OSC 22 to a bounded no-op; no host-action capability is added.
