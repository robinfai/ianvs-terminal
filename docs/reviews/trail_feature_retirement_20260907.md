## 配置与兼容

旧快捷键配置中的退役标识作为不可执行的兼容数据保留；读写往返不丢弃整个配置，也不会让已退役动作重新生效。专属的快捷键编辑选项已移除。旧持久化数据不自动销毁，之后若要清除应另做显式数据迁移与恢复设计。

底层终端库承担协议支持，不以应用动作菜单为裁剪目录。删除产品面板不意味着删掉 OSC 133、OSC 1337、命令输出范围、普通剪贴板和会话进程这些共享基础。

### 2026-09-09 同步改造边界复核

白名单外独立功能继续退役，清理范围包括后台执行，不能只隐藏菜单。为白名单功能服务的协议、加密、存储及旧数据兼容读取可以保留，但不得成为恢复已退役功能的入口。

本轮已将粘贴历史从主动 API 同步文档中移除，删除专属同步绑定、解码及同步包装。旧本地历史仍可由兼容仓读取；不会自动上传旧历史、拉取远端历史或删除任一端旧数据。新增回归约束同步文档不包含 `paste_history`，且同步前后已有远端历史 revision 保持不变。
