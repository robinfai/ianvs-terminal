# 回看最小闭环

日期：2026-09-09。

## 用户路径

工具栏和命令面板的“回看”打开同一个轻量面板：

- 最近画面：回看当前会话的临时输出缓存，退出应用后清除。
- 已保存录制：开始录制、停止保存、按时间倒序查看本机录制。
- 打开录制文件：使用系统文件选择器打开已有文件。

停止保存成功后刷新列表，保留直接回放的成功提示。重新启动应用会从原本地录制目录发现完成文件。点击条目进入现有回放界面，可播放、定位、搜索和复制输出；活动终端会话继续保留。

## 实现边界

复用现有录制仓库、原生录制及回放实现，不增加新的动作标识、API 同步文档或文件格式。将原来不可达的复杂录制库 UI 收敛为最近列表，移除专属排序、过滤、导入、重命名、导出和删除的面板装配及回调；持久化层的现有数据和兼容操作保持原样。

未完成的临时文件不进入列表；损坏文件明确标为不可读取。目录读取失败显示错误与刷新入口，文件选择器仍可使用。保存失败保留现有重试状态，不能显示保存成功。

异步打开携带请求代次，关闭面板或切换回看来源后丢弃旧结果。同一路径再次打开会重建播放器，避免沿用旧内容。展开面板保留现有会话和播放器状态；搜索框在宽度变化时保留文字、选择与焦点，关闭面板恢复之前的键盘焦点。窄屏使用可滚动的覆盖面板，深色和文本缩放复用应用主题。
