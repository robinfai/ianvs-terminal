## Manual confirmation checklist

Use this as the final human pass. If every item passes, the remaining risk is effectively exhausted.

1. Shortcut checks
- In a focused terminal pane, press `⌘F`.
- Expected: `Search scrollback` opens, input focus lands in the search field, and no `f` is inserted into the shell.
- Press `⌘⇧H`.
- Expected: `Paste History` opens directly.
- Press `⌥⌘B`.
- Expected: `Instant Replay` opens directly.
- Trigger `Hotkey window`, then press `⌥⌘Space`.
- Expected: the hidden window returns immediately without a quit prompt.

2. Notification banner delivery
- In macOS `System Settings > Notifications > ianvs terminal`, temporarily enable notifications.
- Keep another app frontmost.
- Run a short command that completes, such as `echo banner-check`.
- Expected: a real macOS notification appears for Ianvs Terminal.
- Expected: frontmost focus stays with the other app.
- After verification, restore the previous notification setting if desired.

3. Cross-display font rendering
- Move the app between the built-in display and any external display in normal and narrow window sizes.
- Expected: terminal glyphs, prompt separators, status chips, and command/search overlays remain crisp and aligned with no clipping or blurry scaling artifacts.

4. Trackpad feel
- Use a physical trackpad to resize the window, switch panes, and scroll through terminal output.
- Expected: resize feedback feels continuous, pane hover/focus changes feel predictable, and scroll behavior does not jump or stall.
