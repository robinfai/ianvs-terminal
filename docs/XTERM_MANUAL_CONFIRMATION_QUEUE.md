# xterm.js Manual Confirmation Queue

Purpose: collect xterm.js audit risks that cannot be fully confirmed by local automated probes alone. Process this queue only after automated/source-confirmable rows in `docs/TERMINAL_XTERM_RECENT_FIX_AUDIT.md` and T-069 through T-076 have been updated with their latest evidence.

## Rules

- Do not change product code from this queue alone.
- Record actual observations before creating implementation work.
- If a manual probe confirms a product gap, create a smaller follow-up task card under `docs/tasks/` and link it from the audit.
- If a manual probe passes, update the audit row with the date, platform, command or steps, and mark the row `Covered` or `Likely covered` as appropriate.
