# Trail IDE icons

This font supplies Google Material Symbols Outlined at weight 400, optical size
20, grade 0 and fill 0 using Flutter's existing MaterialIcons codepoints. It
covers Trail and shared ianvs_design components without changing icon identities.
The original SDK font has fixed strokes; IconTheme.weight cannot change it.
The legacy asset filename is retained to preserve packaging references.

The pubspec intentionally disables automatic Material Icons inclusion and
registers this replacement explicitly. Flutter may warn that a dependency
requests Material Icons; the bundled font supplies that family. Enabling the
automatic font as well would duplicate the family.

Source: https://github.com/google/material-design-icons/tree/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/variablefont

Inputs: MaterialSymbolsOutlined[FILL,GRAD,opsz,wght].ttf and .codepoints,
downloaded 2026-10-31. SHA-256:

- TTF: f7837ba8573d9a7a74931618ced8307bc81f96d49af296bf6c8052c772ed5282
- Codepoints: a7404d9e5a1b63f496cf05ace45d386075886b5a7f123fba9f29527cb6006fde

Regenerate from repository root (Python with fonttools installed):

```sh
python tools/build_light_material_icons.py \
  /path/to/flutter/bin/cache/artifacts/material_fonts \
  /path/to/MaterialSymbolsOutlined.ttf \
  /path/to/MaterialSymbolsOutlined.codepoints \
  example/assets/fonts/TrailLightIcons.ttf --weight 400 --optical-size 20
```

Names absent from Symbols retain their original SDK outlines; the generated
fallback list is included. All icons currently referenced in example/lib have
a Symbols mapping. Both upstream licenses are included alongside this file.

## IDE redesign assessment

The previous 300-weight font was already one consistent outline family; Flutter
icon-name suffixes did not represent different rendered stroke styles. At 16 px,
its close, plus, arrow and gear contours were comparatively faint beside text.
A production-font comparison at 16/20/24 px in both themes selected weight 400.
Desktop toolbar glyphs use 16 px; navigation and touch glyphs use 20 px without
reducing hit targets. `AppIcons` supplies semantic roles for configuration pages.
No icon assets generated by an image model are shipped.

Use `lib/ui/previews/icon_design_preview.dart` for the native catalogue and
`test/design/icon_design_capture_test.dart` for rendered inspection. Pass
`ICON_CANDIDATE_FONT` to compare a proposed font against the bundled production
font, and `FULL_UI_EVIDENCE_DIR` to save captures. Production settings, Profile,
SSH and shell captures load the real font, rather than Flutter's SDK substitute.
