# Bundled terminal font provenance

The unchanged JetBrainsMono Nerd Font Mono faces are from Nerd Fonts v3.4.0, based on JetBrains Mono v2.304. The fonts include Nerd Font icon coverage; they are not the plain JetBrains Mono screenshot font vendored elsewhere in this repository.

Flutter registers these faces under the logical family `JetBrainsMono Nerd Font Mono`, namespaced by the package at runtime. Regular, Bold, Italic and BoldItalic cover ANSI emphasis without relying on a host-installed font. CJK and color emoji remain system fallback fonts and are not bundled.

These font files are distributed under SIL Open Font License 1.1. OFL.txt is the exact pinned Nerd Fonts family license; JETBRAINS-OFL.txt is the exact upstream JetBrains v2.304 license; NERD-FONTS-LICENSE.txt contains Nerd Fonts licensing and patcher attribution. The original copyright notices and binaries are unchanged.
