Product feel

先把每天都会碰到的终端体验做稳。

01

本地会话不绕路

打开 shell、运行命令、复制输出、滚动回看，路径直接，状态清楚。

02

终端知道上下文

Shell Hook 让命令、目录和退出状态成为可用线索，而不是只留在屏幕文本里。

03

问题能追到证据

诊断导出把命令负载、native 解析和 Flutter 渲染分开看，减少猜测。

Engineering proof

Flutter 做界面，native core 管终端底层。

分层不是装饰，它让 UI、runtime、PTY 和 Rust core 各自负责一件事，也让功能亮点能继续生长。

看技术页
UI shell

窗口、tab、profile、开源试用入口。

flutterm_terminal

viewport、输入模式、选区、行级缓存。

flutterm_pty

PTY 会话传输和 native JSON 请求通道。

Rust native core

PTY、VT 解析、frame diff、shell hook、诊断证据。

Feature highlights

不只把字节显示出来。

  1. 01Native JSON 请求通道搜索、选区、滚动历史和诊断走同一条扩展通道。
  2. 02Shell Hook 感知终端命令、目录和退出状态可以成为产品线索。
  3. 03行级渲染缓存大输出时尽量只处理真正变化的行。
  4. 04可归因诊断导出把命令、native 解析和 Flutter 渲染分开看。
  5. 05xterm 风格 Dart API用熟悉的终端模型接入，不必先理解 Rust 细节。
  6. 06模式感知输入系统按键、粘贴、鼠标和滚动跟随当前终端模式。
  7. 07Instant Replay 轻量回放用文本快照回看最近画面变化。
